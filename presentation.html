Context

End User

Students, faculty, and staff at Innopolis University who want to discover, organize, and attend campus events.

Problem

Events at Innopolis are scattered across dozens of Telegram chats. There is no central platform to discover what's happening on campus, no map-based view of event locations, and no way to register or track participants.

Product Idea

A Telegram Mini App with an interactive campus map where users can create, discover, and join events at any location in Innopolis.

3 / 5

Implementation

Version 1 — Core MVP

  • Interactive Leaflet map of Innopolis
  • Event creation by tapping map location
  • Event registration / unregistration
  • 9 event categories with filters & search
  • User profiles synced from Telegram
  • Bilingual support (Russian / English)
  • Telegram bot with WebApp inline buttons
  • Auth via Telegram initData

Version 2 — Enhanced

  • Event chat — discuss in real time
  • Photo upload for event posters
  • Telegram-native theme integration
  • Dynamic bot URLs (tunnel auto-update)
  • Improved UI matching Telegram design
